# JPref
JPref is Java program to play Russian Preference (преферанс).  

[documentation](http://jpref.elementfx.com/)  

[документация](http://jpref.elementfx.com/ru)  

The program can be built with IntelliJ or Maven. There are three data files in etc/doc directory, tyatsky-1, tyatsky-2 and
tricks-src that are the sources for JPref resource files. File prebuild can be used to build from them in case they are
updated.
