JPref

Настоящая программа играет в преферанс, два бота против человека. Игра по-честному, без подглядывания и жульничества. Она не требует интернета, за исключением случая, когда пользователь решит послать мне свои замечания, как описано ниже.
Предлагаемая версия еще очень далека от конечного результата. Несмотря на все мои усилия, там наверняка есть баги, так что Ваши критические замечания будут приняты с вниманием и благодарностью.
Наиболее серьезное ограничение - эта версия JPref не умеет вистовать втемную, так что эта возможность избегается или не допускается. Таким образом, нет обязательного виста на шести пик (Сталинград). Также, в целях лучшего тестирования, JPref всегда вистует, даже если это явно не имеет смысла.

Установка

Программа работает на всех OS, поддерживающих стандартную Java, таких, как Windows, macOS, Linux, и т.п.
Для установки программы необходима JRE 1.8 или более новая версия.
Если у Вас JRE не установлена, Вы можете найти все инструкции по установке здесь: www.java.com/ru/download/help/download_options.html. Если Вы не планируете участвовать в разработке проекта и просто хотите поиграть с программой, достаточно установить JRE, JDK иметь не обязательно. В этом случае воспользуйтесь уже готовой программой здесь.

Запуск

Откройте Terminal окно (cmd.exe на Windows) и напечатайте:
java -jar <path to jpref.jar> [список раздач]
Если указан необязательный файл со списком раздач, то программа использует его вместо того, чтобы раздавать карты случайным образом. Это позволяет надежнее тестировать программу.
В качестве списка раздач можно использовать лог, сгенерированный самой программой (см. ниже), что позволяет переиграть сыгранные игры.


Использование

Процесс игры с программой достаточно очевиден.
Кнопка в правом нижнем углу вызывает меню:
  • Пуля - показать текущее положение.
  • Последняя взятка - показать ее.
  • Ваше предложение - договориться о результатах раунда.
  • Комментарий - см. ниже.
  • Послать лог - см. ниже.
  • Настройки - угадайте.
  • Описание - данный файл/окно.
В дополнение к настройкам, которые устанавливаются явно, расположение и размер окна сохраняются. JPref в следующий раз откроется на том же месте.
В конце раунда показывается текущее положение в пуле. Если в этот момент нажать на кнопку Проверить, последний раунд будет переигран в ручном режиме, когда все ходы всех игроков делаются вручную и показаны все карты. Это позволяет проверить все ходы и найти ошибки программы.

Важной особенностью программы является ведение логов, куда записываются все игры. Логи располагаются в logs директории, либо "рядом" с jpref.jar файлом (Mac OS, Linux) либо в <ваша домашняя папка>\jpref (Windows). Новый лог открывается при смене дня, последующие запуски программы продолжают то же лог.
При нажатии на меню Комментарий появляется окно для комментариев. Особенно важно заносить комментарии об ошибках программы, глупых ходах и т.п.
Весь напечатанный текст попадает в лог, который может быть послан разработчику:
  • Через меню. Ограничение - только текущий лог.
  • Через github - open new issue.
  • Послать лог файл на ab.jpref@gmail.com
